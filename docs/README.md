# Documentation

This repository contains public technical documentation only. English is
required. Private conversations and working records do not belong here.

Read the guide matching the task, rather than loading every policy at startup.

| Guide | Read when |
|---|---|
| [Git workflow](contributing/git-workflow.md) | Creating branches, commits, PRs, or merges |
| [Documentation](contributing/documentation.md) | Writing or reviewing a README or other document |
| [Code and comments](contributing/code-style.md) | Changing code, tests, or comments |
| [CI guards](contributing/ci-guards.md) | Changing checks, hooks, workflows, or action dependencies |
| [Architecture](architecture.md) | Adding or changing application code, configuration, or module interfaces |
| [Running locally](running.md) | Starting the application or running tests |
| [Design system](design.md) | Building pages with shared tokens, components, and payment wording |

Keep this index current when adding or moving a guide. Rules apply equally to
human and automated contributors. External references are supporting sources,
not instructions to execute or permission to publish.
